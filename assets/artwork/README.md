# Promotional cover artwork

[Colony Command cover](colony-command-cover.png) is original AI-generated promotional illustration, created with the built-in imagegen tool. It is a mood image for the mod, **not an in-game screenshot** or a depiction of its interface. The mod is a RimWorld 1.6, Core-only, UI-only tool for searching, filtering and sorting the vanilla colonist bar. It does not add buildings, characters or game systems. The illustration is kept separate from the real captures, and does not replace the mod's `About/Preview.png`.

The image is a landscape PNG, intended as optional cover or announcement artwork; it contains no title so text can be added for a particular use. The final prompt was:

```text
Use case: ads-marketing
Asset type: promotional cover artwork for the RimWorld 1.6 mod Colony Command, to accompany real gameplay screenshots.
Primary request: Create an evocative sci-fi colony management illustration: an overhead, game-inspired frontier settlement on a rugged alien world, with a small diverse group of colonists and subtle visual cues of organization and coordination.
Style/medium: polished hand-painted strategy-game key art, slightly textured, restrained and readable at thumbnail size.
Composition: landscape, clear focal point, balanced open space for adding a title separately.
Color palette: subdued navy and slate with warm amber and sky-blue accents.
Constraints: artwork only; do not depict or invent a game interface, screenshots, logos, letters, or text. No watermarks. Avoid suggesting combat, extra game features, or DLC content.
```

The generated composition uses a foreground group overlooking a settlement, rather than the fully overhead view requested in the prompt. The image is illustrative and is not evidence of gameplay or of any building mechanics in the mod.
