# Changelog

## 1.0.0 — 2026-11-15

First official release. RimWorld **1.6**, **Core** only — no DLC and no other mods are required. The mod is UI-only and saves no data, so it can be added to or removed from an existing save; filter and sort state resets when a game is loaded.

- **Search by name** — the bar narrows to matching colonists as you type (Enter selects the first result; Escape dismisses the field).
- **Status filters with live counts** — Drafted, Injured, Idle and Inspired. Filters never change colonists or their saved order.
- **Skill filter** — pick a skill and a minimum level (Any / 0+ / 5+ / 10+ / 15+).
- **Sorting** — by name, mood or the selected skill, in either direction; restore the vanilla order with one click.
- **Panel in the right column** under the Learning Helper; when the column is too short it folds into a compact search field and a Filters menu.
- **Reset** — clears every control back to the vanilla bar, including drag reorder.
